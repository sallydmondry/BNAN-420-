Design decisions

  • Independent agents run in parallel: agents 2–5 don't depend on each other, so Stage 2 runs them together.
  • Deterministic money math: every dollar comes from code over public data (core/finance.py), never from a language model.
  • Evidence over guessing: each field cites its quote; missing items say "not stated in offer."
  • Runs with no API key: each agent has a local engine; Claude is optional for language tasks only, and a guard rejects new dollar figures.
  • Private: offers are processed in memory, never stored or logged; results expire in 30 minutes.
  • Verified: 195/195 sample fields extracted correctly; take-home exact to the cent vs. an independent worksheet; 102 automated tests.
Stack: FastAPI + pydantic (typed agent contracts in core/models.py) · React + TypeScript + Tailwind · Server-Sent Events · Docker. Built with Claude Code. Estimates for comparison, not financial advice. Sample companies and reviews are SIMULATED.
